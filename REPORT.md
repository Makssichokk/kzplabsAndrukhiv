# Звіт до лабораторної №4
**Тема:** Потокова обробка даних у Java-проєкті. **Варіант:** 1. **Предметна область:** Каталог книжок.

## Мета
Переписати основні обчислення та реалізувати п’ять запитів Stream API й Optional-пошук зі збереженням поліморфної моделі та старого зовнішнього звіту.

## Стан до та після
| Компонент | Лабораторна №3 | Лабораторна №4 |
|---|---|---|
| Середні сторінки | цикл, сума | summarizingInt().getAverage() |
| Найдорожча книга | цикл із порівнянням | max(comparingDouble) |
| Загальна ціна | цикл | mapToDouble().sum() |
| Запити | відсутні | BookQueries, 5 запитів і Optional |
| Звіт | стандартний, --reading-costs | той самий, додатково --queries і --find |

## Контракт даних
Збережено Book, PrintedBook, ElectronicBook, BookFormat, equals/hashCode, вартість читання. Старий CSV має 4 поля `title;author;pages;price`. Для нового завдання потрібні рік і жанр, тому дозволено 6 полів `title;author;pages;price;year;genre` без зміни старого файла. Для старих записів рік/жанр відсутні; жодні значення не вигадуються.

## П’ять запитів і пошук
| № | Метод | Stream API | Результат |
|---|---|---|---|
| 1 | recent | filter(year >= 2020) | List<Book> |
| 2 | titles | map(Book::getTitle) | List<String> |
| 3 | countByGenre | groupingBy(..., TreeMap, counting) | Map<String,Long> |
| 4 | pageStatistics | summarizingInt(Book::getPages) | IntSummaryStatistics |
| 5 | top | sorted(comparator).limit(N) | List<Book> |
| 6 | findByTitle | filter(...).findFirst() | Optional<Book> |

## Компаратор
`Comparator.comparingInt(Book::getPages).reversed().thenComparing(Book::getTitle)` — сторінки за спаданням, назва за зростанням. Сортування перед limit забезпечує правильний топ. N=0 — порожній список; N<0 — виняток.

## Optional
Пошук повертає першу книгу з відповідною назвою; `null` або відсутній ключ повертає `Optional.empty()`. Дублікати назв у map зберігаються.

## Результати контрольного запуску
У `data/input-lab04.csv` 8 коректних і 2 помилкових записи. Середня кількість сторінок — **272.50**, сумарна ціна — **1920.00 грн**, найдорожча — **Тигролови (310.00 грн)**. За жанрами: Драма — 1, Поезія — 3, Повість — 2, Роман — 2. Сторінки: кількість 8, сума 2180, мінімум 160, середнє 272.50, максимум 350. Для 2020+ знайдено 6 книг. Топ-5: Тигролови, Кобзар, Кобзар, Маруся Чурай, Місто.

## Порівняння реалізацій
Stream API відділяє логіку запитів від форматування та усуває зовнішній змінний стан. Колекція не змінюється. Старий звіт без `--queries` зберігає свій формат. Паралельні потоки не використовуються, бо даних небагато.
