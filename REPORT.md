# Звіт до лабораторної роботи 6. Варіант 1: Бібліотека

## Формат CSV

Заголовок: `title,author,year,pages,genre`.

| Поле | Тип після читання | Правило |
|---|---|---|
| title | str | не порожнє, зайві пробіли прибираються |
| author | str | не порожнє, зайві пробіли прибираються |
| year | int | ціле число, не менше 0 |
| pages | int | ціле число, не менше 0 |
| genre | str | не порожнє, зайві пробіли прибираються |

Рядок із комою й лапками екранує сам модуль `csv`: `"Quantum ""Garden""",Bob Stone,2023,450,science` читається як назва `Quantum "Garden"`.

**Правила порожнього входу.** Файл лише із заголовком дає порожній список і коректний звіт із нулями. Файл без заголовка дає `DataError("Порожній CSV: немає заголовка")`. Дублікати рядків не є помилкою: їх враховують як окремі записи, а множина авторів лишається унікальною.

## Структура модулів

| Модуль | Призначення |
|---|---|
| `errors.py` | клас `DataError(ValueError)` з атрибутами `line` і `field` |
| `loader.py` | `parse_row`, генератор `iter_records`, `load_records`; читає CSV, перетворює типи, додає номер рядка до помилок |
| `analysis.py` | відбір, множина авторів, словник за жанрами, `summarize` з `*args/**kwargs`, `make_summary`, `stream_summary`; файли не відкриває |
| `reporting.py` | `format_report` і `write_report`; CSV не читає |
| `cli.py` | аргументи, коди завершення, межа помилок |

Код запуску міститься лише в `cli.py` під `if __name__ == "__main__":`, тож імпорт модулів нічого не виконує (є тест).

## Перетворення даних

- **Список:** `load_records` повертає `list[dict]`; відбір `[r for r in records if r["year"] >= minimum_year]`.
- **Множина:** `{str(r["author"]) for r in records}` — унікальні автори.
- **Словник:** `{g: sum(1 for r in records if r["genre"] == g) for g in sorted(genres)}` — кількість книг за жанрами, ключі впорядковано.
- **Типи полів:** `year`, `pages` — `int`; текст нормалізується через `" ".join(text.split())`.

## Функції

`summarize(records, *metrics, minimum_year=2020, **labels)`:

- `minimum_year=2020` — типове значення (незмінний об'єкт, стану між викликами немає);
- `*metrics` — назви числових полів (`year`, `pages`);
- `**labels` — підписи метрик.

Невідома метрика дає `ValueError`, порожній після відбору набір дає суму 0. `make_summary` рахує `pages`, а `stream_summary` дає той самий результат за один прохід без збереження записів.

## Алгоритм аналізу

1. Відбір: `year >= minimum_year` (за замовчуванням 2020, межа входить).
2. Множина унікальних авторів.
3. Словник кількості книг за жанрами.
4. Сума сторінок за відібраними записами (для порожнього набору 0).
5. Найдовша книга: `min` за ключем `(-pages, title, author, year, genre)`, тому за рівності сторінок вибір однозначний.

Звіт не залежить від порядку рядків у файлі (є тест).

## Обробка помилок

| Ситуація | Виняток / код | Повідомлення | Причина (`from`) |
|---|---|---|---|
| Хибний `year` | `DataError`, код 1 | Рядок N: поле year має бути цілим числом | `ValueError` |
| Хибний `pages` (`abc`, `12.5`, `1_000`) | `DataError`, код 1 | Рядок N: поле pages має бути цілим числом | `ValueError` |
| Від'ємне значення | `DataError`, код 1 | Рядок N: поле pages має бути не менше 0 | немає |
| Порожнє або відсутнє значення | `DataError`, код 1 | Рядок N: поле genre порожнє | немає |
| Забагато полів | `DataError`, код 1 | Рядок N: забагато полів | немає |
| Відсутній стовпець | `DataError`, код 1 | Відсутні стовпці: pages, genre | немає |
| Файл без заголовка | `DataError`, код 1 | Порожній CSV: немає заголовка | немає |
| Файл не в UTF-8 | `DataError`, код 1 | Файл не є коректним UTF-8 | `UnicodeDecodeError` |
| Файла немає | `OSError`, код 3 | Помилка файла: ... | — |
| Помилка аргументів, збіг вхідного й вихідного шляху | `argparse`, код 2 | довідка про використання | — |
| Неочікувана помилка | код 4 | Неочікувана помилка: ... | — |

Голого `except` немає; `except Exception` використано лише на межі CLI. `raise ... from error` зберігає першопричину, і CLI виводить її рядком «Причина:». Номер рядка — це номер фізичного рядка, де закінчився запис (заголовок має номер 1).

## 1. Файловий звіт

Звіт записується через `Path.open("w", encoding="utf-8", newline="\n")` у блоці `with`; каталог створюється через `mkdir(parents=True, exist_ok=True)`. Для `data/input.csv` очікуваний текст (`baseline/summary.txt`):

```
Звіт: бібліотека, книги з року 2020 і пізніше
Кількість книг: 6
Сумарна кількість сторінок: 1930
Найдовша книга: Quantum "Garden" (Bob Stone, 2023), 450 стор.
Кількість книг за жанрами:
  novel: 3
  poetry: 1
  science: 2
Автори (3):
  Ann Lee
  Bob Stone
  Олена Коваль
```

Вхідний файл не змінюється (є тест). Коди завершення CLI: успіх 0, пошкоджений CSV 1 (звіт не створюється), відсутній файл 3, виклик без аргументів 2.

## 2. Тестування

`python -m pytest`: **[підставте результат]**.

- Коректні дані: типи, нормалізація пробілів, текст звіту, порядок рядків, CRLF і BOM.
- Порожній вхід: лише заголовок, порожній файл, порожній відбір, порожній звіт.
- Дублікати: зберігаються, множина лишається унікальною, словник їх враховує.
- Помилки: хибне число, від'ємне й порожнє значення, зайві поля, відсутній стовпець, `__cause__`, номер фізичного рядка.
- Текст із комою: назва з комою й лапками читається коректно.
- Функції: `summarize` з типовим значенням, `*args` і `**kwargs`, порожній відбір, невідома метрика.
- Файл і CLI: UTF-8 з `\n`, перезапис, коди 0–4, повідомлення в stderr, запуск через `python -m kzp_lab06.cli`, збіг з еталоном, імпорт без побічних ефектів.

**Зірочка (потокова обробка).** `iter_records` — генератор, `stream_summary` обчислює підсумок за один прохід, `itertools.islice` бере перші записи без читання всього файла. `scripts/measure_memory.py`, 200 000 рядків (`tracemalloc`, Linux, Python 3.12):

| Режим | Піковий обсяг пам'яті | Час |
|---|---|---|
| Список записів (`load_records` + `make_summary`) | 75.49 МіБ | 2.95 с |
| Потоковий (`iter_records` + `stream_summary`) | 0.10 МіБ | 2.56 с |

Звіти обох режимів однакові. Обмеження: `tracemalloc` вимірює лише пам'ять Python, цифри залежать від машини й версії Python, виграш за часом невеликий.

## Висновок

У роботі створено Python-пакет `kzp_lab06` (варіант 1, Бібліотека), який читає CSV, відбирає книги з `year >= 2020` і записує стабільний текстовий звіт: кількість книг, сумарні сторінки, найдовшу книгу, кількість книг за жанрами та список авторів.

Код розділено на модулі зі своїми обов'язками: читання, обчислення, звіт і CLI. Помилки даних повідомляються як `DataError` з номером рядка й назвою поля, CLI повертає окремі коди завершення, вхідний файл не змінюється. Потокова обробка зменшила піковий обсяг пам'яті із 75.49 до 0.10 МіБ на 200 000 рядків. Пакет збирається у wheel, тести покривають коректні та порожні дані й усі типи помилок, а CI налаштовано для трьох операційних систем.
